# Prompt d’intégration assets LUMIA pour Claude Code

Place le dossier `public/images/lumia` dans le projet Next.js. Utilise `hero-main.webp` comme hero homepage, `facade-storefront.webp` pour la section local, `birthday-premium.webp` pour la page anniversaires, `workshop-natural.webp` et `workshop-family.webp` pour les ateliers, `sensory-room-soft.webp` et `sensory-wow-room.webp` pour la salle sensorielle.

Crée une galerie premium avec les images WebP, utilise `/thumbs` pour les miniatures, `/og` pour les metadata OpenGraph et `/social` pour les déclinaisons Instagram.

Mention prudente dans le site : “visuels conceptuels — direction artistique du projet” tant que le local réel n’existe pas.
